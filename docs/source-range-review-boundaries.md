# 来源范围审核与作品身份边界

图库规范博主、Work 和本地副本是主体。来源页面只是外部证据；来源编号连续、
名称相近或压缩包存在，均不能单独证明两个本地作品相同。

## 三层职责

1. 来源适配层解析原文、NO/VOL 范围、媒体合计及来源专用格式，保留原始声明。
2. 范围审核确认该来源声明所对应的明确逐项条目及文件。覆盖检查不能代替审核，
   不按区间生成标题、Work 或均摊图片数。
3. 作品身份层消费[共享标题解析结果](./title-identity-boundaries.md)，在规范博主范围内
   区分精确身份与待人工核对候选，不用来源的宽松格式兼容规则自动绑定本地作品。

## 通用范围凭据

`CostuanRangeReviewStore` 保存服务端审核记录：规范博主、页面、合集标题、目录原文、
审核时间、理由和全部明确条目。每项须有独立编号、完整原始标题和规范 `.7z` 文件名。
记录不可隐式覆盖；校验无误后才允许沿用，任何增删、范围或标题改变重新暂停。
这不是允许插件提交“已审核=true”的接口。

已有来源兼容只读取数据库现有逐项事实：合集快照一致、SourceWork 与保存的目录条目一致，
且历史原分享证据覆盖每个范围成员。缺记录或证据不明确时维持待审核；不补建历史关系。
原 Ely 专例由该通用事实校验接替，不含博主 ID、页面 ID 或固定范围判断。

成功预检返回 `rangeReview`：`policy=explicit-range-v1`、SHA256 `reviewId`、
`creatorId`、`postId`、范围内 `sourceOrders` 和 `requiredFilenames`。
插件核对当前范围后采用 `canonicalWorks`，仍须执行当轮原分享逐文件只读核验。
服务端收取结果时重新校验当前目录与领取轮次，不信任客户端审核标志或历史转存状态。

## 当前边界

- 通用覆盖支持 NO/VOL；当前交接协议只支持每个明确条目对应一个规范编号 `.7z`。
  混合编号产生文件名冲突、一个包对应多作品等情况仍需核对，不能自动猜测。
- 范围成员不继承合计媒体数；无独立标题的既有占位记录只作为来源事实保留。
- 新范围审核通过现有服务层显式登记，尚未提供通用网页审核编辑器；普通本地入库不受此限制。
- 不改正式来源绑定、本地满足、原计划或接纳历史；不合并 Work、不重跑采集。
- 新旧插件/服务端协议不匹配时安全暂停；开发测试完成不等于已部署或已更新正在使用的扩展。
