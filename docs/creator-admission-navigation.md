# 图库账本与博主入库导航

本轮为前端容器、路由和读取生命周期调整。原业务 API、计划/Job、来源规则和数据库结构保持；不要求本地接纳先具有 Costuan 来源。

## 入口

| 入口 | 当前归属 |
| --- | --- |
| `/archive-catalog`、`?workspace=roster` | 图库账本 → 博主库 |
| `/archive-catalog?workspace=resources` | 图库账本 → 资源目录 |
| `/archive-catalog?workspace=source/staging/ingest` | 兼容跳转到博主入库 → Costuan对应阶段 |
| `/creator-admission` | 无明确上下文时默认本地入库 |
| `/creator-admission/local` | 多博主本地入库三步流程 |
| `/creator-admission/local/:creatorId` | 单博主本地入库 |
| `/creator-admission/costuan?workspace=source` | 来源检查 |
| `/creator-admission/costuan?workspace=staging` | 网盘暂存 |
| `/creator-admission/costuan?workspace=ingest` | Costuan入库 |
| `/creator-admission/review` | 保留原kind/planId/itemKey/jobId/creatorId审核上下文 |
| `/local-admission`、`/local-admission/:creatorId`、`/local-review` | 保留原query/hash的兼容跳转 |

导航不执行来源检查、任务规划、扫描、恢复或接纳。所有子路由继承管理员权限。明确的旧链接和已保存批次优先于默认模块。

## 状态与边界

模块选择和本地三步进度分为两层。薄父容器在本标签页保留已访问模块，回切恢复原链接；本地已保存草稿继续使用原有会话恢复，不扩展跨设备存储。未提交目录与人工选择不因切到Costuan而清空。审核页按照任务类型高亮和返回，不把Costuan Job当作本地计划。

Costuan三阶段从账本提取为单一实现，未访问阶段不挂载队列；停用阶段停止不必要前端轮询，后台业务不取消。博主库必要统计与来源资料管理仍保留，不等于启动Costuan执行模块。

本轮首次交付为Draft和4241隔离预览；不自动更新4141、不安装Script候选，不自动Ready或合并。保留PR38本地接纳、范围确认、后续完成及防重入语义。数据库仍000026，无新增迁移。

## 桌面任务流程：状态与动作

桌面试用反馈后，Costuan 三阶段及其来源选择、暂存组件已恢复到本轮桌面重排前的界面（参考 d1fb3f1）；本地入库的桌面优化保留。下表描述真实操作职责，不表示 Costuan 使用了新的向导布局或按钮文案。后续界面调整不默认采用大量 `details/summary` 折叠项，先以用户对原界面的反馈为准。

以下依据现有 API 调用链整理，展示层不扩展执行范围。模块标签用于导航，步骤条用于表示进度，主按钮用于推进当前明确任务。

| 页面 / 状态 | 用户要知道什么 | 主要动作 | 次要动作 | 实际副作用 |
| --- | --- | --- | --- | --- |
| 本地：选择图集 | 等待区、规范身份、已选博主与目录 | 下一步：检查所选图集 | 重新读取、调整身份 / 范围、补充来源 | 选择仅前端状态；按需 GET 目录；下一步 POST 盘点并保存预览草稿，不移动文件 |
| 本地：预览草稿 | 可入库 / 待判断 / 跳过暂缓及当前选择 | 查看入库确认 | 修正条目、文件有变动时重新检查 | 重读 POST 可产生关联新草稿；新增范围仍需确认，原计划不改写 |
| 本地：最终确认 | 本次范围、目标、作品对应、副本及具体广告处置 | 确认入库所选目录 | 返回修改 | 原 confirmed 请求进入后台文件移动 / 索引；不是只保存 JSON |
| 本地：回执未知 | 原提交是否已被接受尚不明确 | 核对提交结果 / 重试原提交 | 查看状态 | 冻结原范围及 requestKey；只重传原请求，不另建批次 |
| 本地：运行 / 结果 | 后台进度、真正待处理项和当前去向 | 查看结果 / 按 nextAction 处理具体项 | 历史、技术详情、明确空父目录清理 | 读取进度只读；继续原计划执行原范围；剩余范围预览另存草稿；清理确实回收空目录 |
| 精确审核 | 原 Job / 计划、异常文件及批准范围 | 检查后确认具体恢复决定 | 返回原批次 / Job | inspect 会保存审核会话；execute / retry 可处置精确文件并恢复原任务，不能称零写入 |
| Costuan：来源检查 | 已选博主、固定任务轮次，网页不直接采集 | 准备检查任务 → 复制本次检查范围 | 筛选 / 翻页 / 查看回执 | plan-selected POST 创建 / 复用任务；复制只写剪贴板；采集在原插件执行 |
| Costuan：网盘暂存 | 网盘回执不代表本地下载；下载位置与后续动作 | 按当前任务状态转到插件或客户端下载 | 查看明细；高级全量规划 / 密钥维护 | 队列 GET 只读；全量规划 POST 不限当前筛选；密钥重置会废旧密钥 |
| Costuan：允许范围 | 已保存名单与页面未保存修改不同 | 必要时保存明确范围 | 读取等待区博主、追加 / 替换草稿名单 | 读取目录会枚举文件系统；追加 / 替换只改表单；settings PUT 持久保存 |
| Costuan：检查文件 | 按已保存名单检查稳定压缩包 | 检查压缩包并建立任务 | 设置 / 环境工具 | scan POST 建立或对账 Job，不自动执行入库；不是状态刷新 |
| Costuan：可执行任务 | 全部执行按已保存名单，不限当前页或筛选 | 执行已保存范围内可处理任务 | 指定博主继续 / 具体 Job 审核 | runBatch({}) 消费已保存 allowlist 内可处理任务；creatorIds 入口进一步限定博主，不伪称当前选中行 |
| Costuan：环境异常 | 配置或路径错误及解决入口 | 修正设置 / 明确验证 | 查看技术诊断 | 环境验证会探测工具和目录；回收站测试会创建并回收哨兵文件，不是普通读取 |

桌面优先视口为 1440×900、1920×1080，补 1366×768 与 390px 兼容。合成夹具下的界面启发式验收不等于用户满意度测试。正常入库不要求反复打开设置；未知、空数据和读取失败分别说明。业务范围、人工暂缓、广告取消、后续完成保护、同源回执重传和管理员检查沿用原服务。
