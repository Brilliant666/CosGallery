# 图库账本与博主入库：页面地图

**图库账本用于查看和维护身份 / 目录；博主入库用于明确范围内的资源接纳。** 外部来源不是本地入库的前置条件。

```text
图库账本
├─ 博主库：规范博主、别名、偏好、资料与身份管理
└─ 资源目录：本地 Work 的自有目录、搜索和导出

博主入库
├─ 本地入库：选择图集 → 检查并确认 → 入库结果
└─ Costuan：来源检查 → 网盘暂存 → Costuan入库
```

这些页面要求管理权限。打开标签、查看记录和刷新已有状态，不会自动执行来源检查、网盘转存、扫描、恢复或接纳。

## 当前入口

| 页面 | 路由 | 日常用途 |
| --- | --- | --- |
| 我的图库 | `/library` | 每页 60 位规范博主，名称 / 别名、分级与偏好联合筛选；同一博主的多个物理目录仍聚合为一张卡片 |
| 图库账本 → 博主库 | `/archive-catalog` 或 `?workspace=roster` | 管理规范身份，打开某位博主的来源资料或资源目录 |
| 图库账本 → 资源目录 | `/archive-catalog?workspace=resources` | 优先按明确 URL、当前选择、上次有效范围恢复；无可恢复选择时显示全部博主，可直接搜索选择单个博主 |
| 博主入库 → 本地入库 | `/creator-admission/local` | 一次选择一位或多位博主的已解压作品 |
| 带博主的本地入库 | `/creator-admission/local/:creatorId` | 复用明确规范博主；来源资料入口还会带入所选资料 |
| Costuan → 来源检查 | `/creator-admission/costuan?workspace=source` | 明确本轮检查对象，交给插件读取来源 |
| Costuan → 网盘暂存 | `/creator-admission/costuan?workspace=staging` | 查看缺失文件任务、暂存回执及相关设置 |
| Costuan → Costuan入库 | `/creator-admission/costuan?workspace=ingest` | 检查已下载压缩包、按已保存名单运行本地任务 |
| 具体异常审核 | `/creator-admission/review` | 从任务入口带入原计划 / Job 上下文，查看并处理单项异常 |

`/creator-admission` 在没有明确上下文时进入本地入库。旧 `/local-admission`、`/local-review` 和账本的 `source/staging/ingest` 链接保留兼容跳转及 query/hash，收藏的批次链接不用手工改写；新指南使用上述入口。

资源目录链接已有明确 `creatorId` 或 `scope=all` 时优先恢复相应范围；同时存在时以 `creatorId` 为准。博主卡片入口明确带入该博主。明确链接无效或不可访问时显示准确状态，不静默扩大到全库；失效的历史范围记忆可以清除后使用默认范围。全库链接为 `/archive-catalog?workspace=resources&scope=all`。详见[资源目录入口与范围](own-resource-catalog.md)。

## 我的图库：分页与筛选

`/library` 的分级为“全部 / R15 / R18”，偏好为“全部 / 喜欢 / 保留”，与名称 / 别名搜索同时生效。筛选完整可访问的规范博主集合后再分页，总数与列表使用相同条件；“全部偏好”包含未设置偏好的博主。博主库和资源目录仍每页 50 条，博主页图集仍每页 24 套摘要。

主动修改筛选回到第一页并保持筛选栏可见，不套用旧阅读位置；从博主 / 图集返回恢复筛选、页码和阅读位置。重复选择当前生效的筛选不重新请求或滚动。待分类、未关联和停用的日常筛选标签不再显示在 `/library`；相关数据、权限和博主库管理筛选仍保留。

## 管理资料：四个标签、两个保存范围

博主库卡片只保留**资源目录**和**管理资料**两个主入口。“管理资料”默认打开只读概览，不自动编辑或执行任务；桌面右侧面板打开时仍能浏览左侧列表，窄屏使用同一内容的覆盖式面板。新增博主入口仍在列表顶部。

| 标签 | 内容与主动作 |
| --- | --- |
| 概览 | 只读来源合集、已知待收录、待核查与已有本地入库记录，提供图库 / 资源目录入口；没有来源不代表已收齐 |
| 资料 | 名称、偏好、分级、手工别名组成一个草稿，点击“保存资料”一次提交；来源和历史别名只读 |
| 本地目录 | 关联 / 解除目录及首选目录组成另一份草稿，点击“保存目录设置”一次提交；“为该博主入库”只导航到带规范身份的既有入库页 |
| 来源与补齐 | 明确发起“检查来源”、准备缺失获取任务，查看和保存来源资料；任务动作不混入资料 / 目录保存 |

两个保存范围各自在后端事务中提交；失败不会留下未说明的部分保存。提交携带当前范围的版本，发现并发变化时保留草稿并提示重新核对，不静默覆盖。目录保存必须满足最终归属和首选引用规则，不移动文件、扫描或生成任务。

同一博主切换标签保留草稿；切换身份、关闭或离开时会说明未保存的标签，可返回保存、明确放弃或取消。停用 / 恢复和符合条件的误建身份删除是独立确认动作，不属于普通保存，也没有物理文件夹删除入口。

管理面板使用 `manageCreator` 与 `manageTab` 路由上下文，例如 `/archive-catalog?workspace=roster&manageCreator=123&manageTab=directories`；与资源目录的 `creatorId` / `scope` 分开。关闭面板保留左侧搜索、筛选、页码与位置。`123` 只是链接格式示例，须使用实际可访问的规范博主 ID。

## 本地入库：步骤与动作

详细操作见[本地入库与精确审核](local-admission-web.md)。

| 所在步骤 | 主要动作 | 结果与边界 |
| --- | --- | --- |
| 1 选择图集 | 保存等待区设置、重新读取等待区、选择规范博主及作品目录 | 目录列表不是入库；来源可不选 |
| 1 → 2 | 下一步：检查所选图集 | 盘点明确范围并保存预览，不移动文件 |
| 2 检查并确认 | 行内核对目录边界和处理方式 | 正常新作品预选，冲突与人工暂缓保留，候选不会自动成为确定身份 |
| 2 文件已改变 | 重新读取并核对 | 支持内部文件变化和拆分后新作品目录，产生关联新预览，新增范围仍需确认 |
| 2 返回范围选择 | 点击步骤条“1 选择图集” | 修改草稿范围后仍须下一步重新检查；已提交范围不可编辑 |
| 2 → 3 | 确认入库… → 最终确认 | 提交明确目录、Work、副本和广告清单，后台真实执行 |
| 3 入库结果 | 更新进度、查看图集、具体项处理 | 进度读取不重扫；关闭页面不取消已提交任务 |
| 历史 / 后续 | 入库记录、查看后续结果、后续核对 | 保留旧状态，可靠的后续完成另行显示；不能重跑已覆盖项目 |

**入库记录**是步骤栏右侧的弹窗入口；**批次详情**与**核对说明**按当前状态放在同一工具栏。图集处理保持行内操作，广告附件、核对说明、批次详情分别查看，不需要先穿过多层折叠才能执行主流程。

未提交选择的恢复限于当前浏览器标签页。已确认范围、执行记录和幂等回执由后端持久保存；不是把所有前端编辑永久同步到设备间。明确批次 URL 和入库记录用于重新打开，而不是触发自动继续。

## Costuan：三阶段不是三种完成状态

详细流程见[Costuan 压缩包入库](local-ingest-closed-loop.md)。

| 区域 | 页面动作 | 实际作用 |
| --- | --- | --- |
| 来源检查 | 准备检查任务、复制本次检查范围 | 建立固定检查范围；网站采集由配套插件完成，不是网页按钮直接抓取 |
| 来源检查 | 刷新账本状态（只读） | 只更新账本与任务显示，不创建检查、不访问网盘 |
| 网盘暂存 | 查看队列与明细，按任务状态到插件 / 百度客户端下载 | `staged` 仅代表网盘暂存已核验，不代表已下载或本地入库 |
| Costuan入库 | 读取待入库博主 | 读取压缩包待入库区的博主目录，不自动保存名单 |
| Costuan入库 | 追加到当前名单 / 替换当前名单 | 保存本次名单变化，不覆盖其他环境设置，不自动扫描或运行 |
| Costuan入库 | 编辑当前允许处理的博主 → 保存名单 | 明确允许范围；未保存修改时扫描和批量运行不可用 |
| Costuan入库 | 扫描待入库 | 检查稳定压缩包并建立 / 对账 Job；不是只读状态刷新 |
| Costuan入库 | 运行可处理任务 | 消费已保存名单内可处理任务，不限于当前页 / 当前筛选，不自动批准待核查任务 |
| 具体 Job | 继续 / 查看并处理 / 清理重试等可用入口 | 按原任务状态执行，不创建另一种入库历史 |

**入库设置与环境工具**位于 Costuan入库右上角，以弹窗配置路径、工具和密码；右上角密码状态在弹窗内保留。密码可直接查看修改；取消不保存，未改变不覆盖，明确清空保存后不再回退环境值。普通状态接口不返回密码，专用管理读取受鉴权保护。加密恢复材料见[密码配置](local-ingest-password-settings.md)。

名单在主页面管理，与环境设置独立保存。环境验证会探测目录和工具；回收站测试会创建并回收哨兵文件，不能当作普通只读刷新。

## 状态恢复与暂停

模块切换保留本标签页的已访问上下文；未访问的 Costuan 阶段不会为展示而挂载全部队列。离开页面会停止不必要轮询，不取消后端工作。重新打开历史批次不会自动执行旧队列。

暂停先读具体原因：范围、身份、文件证据、活动任务、源包或工具问题要分别处理。来源失败不等于“本地不能入库”；反之，保存来源资料也不等于获得自动获取批准。审核页保持原任务类型，Costuan Job 不会转换成本地目录计划。
