# 删除博主

博主库中的所有身份使用同一删除规则，不区分手工创建、首批名单或其他来源。需先停用，并经服务端确认没有本地作品（包括回收站内作品）、目录绑定或其他阻断关联。删除不可恢复，不会自动把资料或别名归入另一位博主。

## 网页操作

博主库 → 管理资料 → “资料”标签 → “删除博主” → 检查是否可删除 → 核对范围 → 确认删除博主。

先保存或明确放弃资料、目录、来源标签中的草稿。启用中的博主也能看到入口；检查会提示先停用。预览逐项列出名称与别名、图库标签、来源身份、来源合集、来源作品记录和纯来源独立作品的数量，以及阻止删除的具体关联。存在阻断时不提供确认删除按钮。

本地作品为 0 是必要条件，不能仅根据列表数字直接删除。没有本地副本的来源资料可以随身份删除；回收站仍占用本地作品，必须先按作品流程处理。删除博主不移动、回收或永久删除任何本地文件。

同一人被重复建立身份时，可在条件满足后删除多余身份，再单独把需要保留的名字添加为主身份的别名。停用仍保留名称冲突保护，不得通过“确认是不同的人”绕过同人冲突；删除才释放被删身份占用的名称和别名。已有作品需要保留关联时，不能用此入口代替身份归并。

## 接口与再次核验

- `GET /api/admin/archive-catalog/creators/:id/deletion-preview`：只读预览，返回 `blockers` 和 `removalScope`。
- `DELETE /api/admin/archive-catalog/creators/:id`：严格接收 `{confirm:true,confirmationToken}`，沿用管理员能力与变更请求保护。
- 确认 token 绑定目标身份及完整随删资料快照，不代替权限或引用复核。
- 提交时在写事务内重新核对。任何资料或引用变化都会使旧确认失效，必须重新预览；前端不会自动重试删除。

## 删除边界

允许删除的范围有明确白名单：目标身份、所属别名、图库标签及来源身份、所属来源合集及来源作品记录，以及没有本地副本且没有外部引用的独立作品。共享归属、其他身份的引用及范围之外的业务记录不会被级联清除。

服务端检查实际外键、规范身份与作品关联，以及原计划、决定、恢复记录等业务 JSON 中的引用。目录绑定、本地副本（含已回收）、任务、未决计划和无法安全处理的历史引用都可能阻断；仅停用或任务已结束并不保证可删除。无法解析的业务资料保守阻断，并给出原因。正在执行的接纳/索引锁也会阻断，不由删除操作接管或清除。

历史记录中仍有实际业务关联时保留原有阻断，不将它们改挂到另一个人。成功删除时保存独立审计快照，用于追溯本次操作与删除范围；审计不继续占用名称，也不作为新的活跃身份。预览只返回范围数量及阻断原因，不返回文件清单、设置值或凭据。

## 原子提交与派生目录

随删资料、删除审计及目标博主的派生目录更新在同一事务提交；任一步失败全部回滚。既有标脏触发器与目录 publication 更新使旧 Worker 不能发布已删除身份的数据。其他博主的事实和目录状态保持独立。

本入口是明确触发的删除审查，不扫描图库文件，不解码或计算媒体哈希。它不提供批量删除或同人归并。具体身份删除及别名添加是单独的业务操作，不因安装、部署或合并自动执行。
