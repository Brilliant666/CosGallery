## 实现范围

本记录对应 PR52 从研究进入实现后的变更。用户已确认四个图库博主标签及访问边界；此前的[只读研究](./creator-taxonomy-readonly-review-v1.md)保留为实施前证据。

| 操作 | 当前候选行为 |
| --- | --- |
| 点击导航“图库”文字 | 回到全部，清除标签、分级、搜索、偏好和分页条件，回到列表顶部 |
| 点击独立下拉箭头 | 只显示 Cosplay、写真、自拍、福利姬四项；一次进入一个分类 |
| 分类页 | 展示对应规范博主，可按名称搜索；不显示分级控件、分级徽章、卡片分类标签或编辑分类入口，也不保留隐藏分级条件 |
| 全部图库 | 保留 R15/R18 独立筛选；未设置标签的博主继续正常显示 |
| 管理员编辑分类 | 仅全部图库卡片提供有边框的“编辑分类”按钮，与分类标签并排；窄卡片使用带文字提示的铅笔图标。四项多选，支持清空、取消和保存 |
| 返回浏览 | 博主、作品和 Viewer 返回路径保留分类上下文；主动点击图库则重置 |
| 喜欢／保留 | 仅管理员可以查看和使用；匿名与 viewer 的界面、查询及响应均隔离 |

一位规范博主可出现在多个分类，同一列表按规范身份显示一次。标签不进入 Work、LocalWork、别名或来源身份，不自动推断分级；没有全库自动赋值。

## 数据与接口

- 新增 `000031_creator_gallery_labels.sql`：标签关联表 `archive_catalog_creator_gallery_labels`，以及规范博主的 `gallery_labels_revision`。主键约束防止同一标签重复；允许值固定为 `cosplay/portrait/selfie/fuliji`。新建库 schema 与迁移后结构一致。
- 公开列表使用 `GET /api/cos-gallery/creators?label=cosplay`。标签过滤在分页前执行；只要指定有效标签，服务端会忽略旧 `contentRating` 条件。原来的活动／可见范围继续生效。
- 规范博主响应增加 `galleryLabels`。管理员通过 `GET/PUT /api/admin/archive-catalog/creators/:id/gallery-labels` 读取或保存；写入仍走既有管理权限和 CSRF 机制。
- 保存提交 `galleryLabels` 与 `expectedRevision`。事务内检查版本，过期返回 `409 GALLERY_LABELS_CHANGED`，不覆盖他人保存；弹窗保留草稿并要求重新读取。递增版本覆盖标签改回原值的并发情况。
- 标签加入现有博主删除预览范围、快照、确认令牌与显式删除过程。标签变化后旧删除确认失效；没有改变删除博主的业务前置限制。

## 管理员偏好边界

1. 列表、详情及作品列表内嵌 creator 对象，对非管理员省略 `preference` 字段。
2. 非管理员携带 `preference` 查询参数时，在参数验证及过滤前移除，不能得到站主喜欢或保留的子集及数量。
3. 前端清理当前地址和返回地址中的非管理员偏好条件。身份变化时清理阅读缓存、旧列表及编辑弹窗，并拒绝旧身份下迟到的响应。
4. 分类、站主偏好和既有媒体收藏分别处理；没有新增访客关注功能。

## 分类切换布局修正（2026-10-23）

全部图库的分级组被移除后，分类页原筛选容器会缩短或重新换行；长列表切到空分类时，文档滚动条也可能改变可用宽度。此次修正为分级组保留固定布局空间，分类页仍完全移除分级按钮和徽章；占位不包含可聚焦控件。稳定滚动条空间仅在图库页面生效，离开后恢复原页面样式。

- 原界面在合成 Chromium 的 1440 像素匿名场景复现：计数文字纵坐标从 171 变为 160，新的坐标断言失败。
- 修复后核对 1440×900、390×844、320×740，覆盖管理员、匿名和 viewer，以及全部／四分类共 45 个布局样本。搜索框、计数文字右边缘与纵坐标、结果起点及管理员偏好组最大位移均为 0 像素；长列表与空自拍分类均覆盖，无横向溢出。
- 分类页 DOM 不含分级控件／徽章，占位内没有隐藏的可聚焦目标；进入博主详情后滚动条样式恢复。所有接口响应均为合成数据，不连接正式 4141。
- 22 项既有图库视图与导航测试、Vue 类型检查、前端生产构建及 diff 检查通过。Node 22／24 的最终 Head Verify 结果另见 PR Checks。
- 本地截图和坐标记录：`.mocks/pr52/layout-stability/after/`；复现证据位于相邻 `before/`。本轮没有修改真实标签或部署到 4141。

## 卡片分类展示收敛（2026-10-24）

全部图库保留卡片分类标签，并与管理员编辑按钮放在同一行；多标签可以在标签区域内换行。窄卡片的编辑入口使用有边框的铅笔图标，保留完整可访问名称和“编辑分类”提示。未分类的规范博主仍有管理员编辑入口；匿名和 viewer 可在全部图库看到已有标签，但不能编辑。

Cosplay、写真、自拍、福利姬四个分类页移除卡片标签与编辑入口；切换进入分类页会关闭已打开的编辑弹窗。此次只改变显示和入口位置，不修改标签保存接口、数据结构或既有标签值。四类作为站主手动整理内容的分组，不根据作品标题或分级自动重分。

27 项图库视图与导航测试、Vue 类型检查、前端生产构建通过。隔离 Chromium 核对 1440、390、320 像素宽度下的 45 个布局状态和 6 个单／多标签同排样本：筛选区最大位移为 0 像素，标签与编辑入口无重叠或横向溢出。320 像素首次发现 Cosplay 被截断，调整窄卡片间距后，保留原断言复测通过；浏览器错误和意外请求均为 0。

验证记录保存在本工作树 `.mocks/pr52/card-classification-20261024/QA.md` 与 `browser-final/evidence.json`；全部使用合成数据，覆盖管理员边界、分类页隐藏和导航不写标签。正式服务和真实分类不属于本轮测试范围。

## 展开侧栏为主体留白（2026-10-24）

桌面侧栏原本从 4.85rem 展开到 15rem，但主体一直只留 4.85rem，展开时遮住首列卡片。现在 AppShell 与 SidebarNav 共用折叠／展开宽度和过渡时长；鼠标悬停、键盘焦点位于侧栏、图库分类菜单保持展开时，主体左边距同步增加，收起时同步恢复。分类菜单立即展开的状态同步取消两处过渡；减少动态效果偏好也同时生效。

桌面规则匹配现有生成样式的 `48rem` 断点，手机不留桌面侧栏空间；未改全局断点配置。仅调整主体 margin，不改变 Viewer 的 fixed 定位方式。分类标签、权限、菜单持续展开及真实标签值保持原有规则。

隔离浏览器在修改前复现：1440px 悬停展开期间，侧栏右边缘已经到 79.86px，主体左边缘仍为 77.59px；终态遮挡首列。补充了侧栏与主体逐帧几何比较，旧分类切换坐标检查按相同侧栏状态比较；展开与收起本来就应改变主体位置，不能把这一预期变化混作分类页面跳动。相关证据保存在 `.mocks/pr52/sidebar-spacing-20261024/`。

修复后 27 项图库视图与导航测试通过；隔离 Chromium 核对 1440、1098、980、768 桌面宽度及 767、390 移动宽度，46 次状态／过渡共 1846 帧均无主体或首卡被侧栏覆盖。原 45 个布局状态、6 个分类同行样本继续通过；39 张截图、77 次合成 API 请求，浏览器错误与意外请求均为 0。独立审阅及桌面／手机截图复核通过。正式部署的配套构建、精确 Head CI 和真实标签保护另行记录。

## 点击控制侧栏与首页故事栏修正（2026-10-24）

本节替代上一节的悬停／焦点自动展开规则。桌面侧栏由“更多”上方的展开／收起按钮控制，鼠标经过、获得焦点或打开图库分类不会改变侧栏宽度。AppShell 保存唯一的展开状态，侧栏宽度与主体左边距使用同一时长和缓动；文字保持固定布局并随容器裁切，避免逐字挤压。减少动态效果偏好会关闭这些过渡。

展开选择存入当前浏览器的 `cosgallery.sidebar-expanded.v1`，首次渲染前读取，刷新后恢复；存储不可用时仍可在当前页面切换。图库四分类由自己的箭头控制，切换分类保持打开；收起整个侧栏仅隐藏分类，再展开会恢复刚才的分类开合。隐藏及退出动画中的分类链接不能获得焦点，快速反向切换会恢复正常交互。手机继续使用底部导航。

首页“近期批次”仍被遮挡的原因是 HomeView 沿用旧居中方案，额外向左移动 47px。当前 AppShell 已为侧栏预留空间，因此移除这一偏移及其唯一使用的变量，让首页在可用内容区域内居中。修改前真实 4141 的 1098×892 视口中，侧栏右边缘为 77.59px，而首个故事圆环左边缘为 52.40px，实际存在覆盖。

本次只修改导航和布局，保留用户手动分类。没有修改标签接口、保存逻辑、数据库结构或真实标签。

验证包含 36 项 AppShell／LibraryNavigation／HomeView 专项、Vue 类型检查及独立代码审查。隔离 Chromium 覆盖 70 次状态／过渡、10 个首页布局状态，保留 45 个图库布局样本和 6 个分类同行样本；检查刷新和路由状态保留、存储受限、鼠标与键盘快速反向开合、隐藏链接不可聚焦、分类独立展开、减少动态效果及 767／768 断点。测试发现并修复了隐藏分区标题撑宽收起侧栏的问题，同时检查导航自身的 scrollWidth。

测试使用真实 AppShell 和 HomeView 的根布局、故事栏、Avatar 与 ResizeObserver，并使用合成博主及封面。首页没有帖子且不打开故事弹窗，测试入口对未渲染的 FeedList／StoriesModal 使用空组件，避免引入无关播放器依赖；不作为媒体播放验证。详细结果、截图和失败复现记录保存在 `.mocks/pr52/sidebar-click-20261024/`。正式部署仍须通过最终提交的 Node 22／24 Verify，另行确认配套产物、实际页面及真实标签摘要。
