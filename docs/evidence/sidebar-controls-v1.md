# 侧栏顶部控制与管理员浏览偏好

日期：2026-10-24，PR52。用户确认侧栏交互模式仅在管理员设置中提供，暂不增加匿名访客轻量设置页。

## 行为

- 收起时点击顶部品牌位置展开，不再从该位置跳转首页；首页仍有独立导航。展开时点击右上角细线侧栏图标收起，移除原底部开关。
- 顶部按钮提供辅助名称、提示和可见键盘焦点；键盘展开后焦点到收起按钮，收起后回到展开按钮。收起按钮固定在展开后的横向位置，通过头部裁剪显现，避免动画过程中掠过品牌图标。
- 模式选择移到设置→常规设置→浏览偏好，仅管理员可见。默认点击展开/收起，选择立即生效；复用原浏览器存储键，不并入全站保存，不新增设置API或变更设置路由权限。
- 同页偏好事件即时更新侧栏，跨页storage同步保留有效焦点。写入浏览器存储失败时，当前页保存未落盘模式，离开设置再返回仍保持一致；后续成功保存或对应的跨页更新清除该回退。
- 悬停保留100ms移入、120ms移出及180ms动画。手动收起后抑制原指针重新展开，移出重进、显式展开或新的键盘导航恢复正常。图库分类开合和选择独立保留，顶部按钮的pointerdown不当作分类外部点击。
- 匿名访客继续使用顶部开合，不提供新设置入口或模式控件；已存在的浏览器偏好不被重置。手机导航、业务数据和手工博主标签保持。
