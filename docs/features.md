# 功能与边界

CosGallery 以自己的博主、Work 和本地副本为核心。来源可以先于或晚于本地收录；不是每套图集都必须先进入 Costuan 来源库。

## 页面职责

| 页面 | 当前用途 | 不会因打开页面自动发生 |
| --- | --- | --- |
| 图库账本 → 博主库 | 默认只读概览；资料、本地目录、来源与补齐分标签，资料与目录各自原子保存 | 来源采集、下载、作品合并 |
| 图库账本 → 资源目录 | 优先恢复明确 URL、当前或上次有效范围；无可恢复选择时显示全部博主，支持单博主筛选、搜索、分页、详情、导出 | 媒体扫描、文件改名、补建缺失身份 |
| 博主入库 → 本地入库 | 多博主选目录、预览核对、明确确认、后台接纳与结果 | 未确认范围的自动接纳 |
| 博主入库 → Costuan | 来源检查、网盘暂存、本地下载后的归档入库 | 自动恢复全部旧队列 |
| 图库与 Viewer | 主副本图集、按需详情、图片 / 视频浏览 | 跨路由完整详情的永久缓存 |

[页面地图](creator-admission-navigation.md)列出正常入口与旧链接兼容方式。

博主库卡片保留“资源目录”和“管理资料”；“为该博主入库”移至管理面板的“本地目录”标签，仍使用原有规范身份入口。保存资料与目录设置分别校验、提交和处理版本冲突，不用多个独立写请求拼成一次保存；停用、恢复和误建身份删除继续独立确认。

## 本地入库和审核

已解压资源从网页完成普通主路径，无需命令行；选择多位博主后集中核对，再后台逐项处理。新作品、已有 Work 和同套副本分别确认，身份不明时可暂缓。来源不是必填项。

精确审核针对原计划 / Job 与具体文件。JPEG 超限原件保留、PDF 附件和正常 WebP 各有处理边界；保留原件不等于普通解码成功。历史状态与后续完成去向分别显示，有可靠后续完成证据的项目不会作为普通剩余项再次执行。见[本地入库与审核](local-admission-web.md)。

## 来源、版本与补缺

原始观察、博主归属、批次出处、Work 映射与本地满足不是同一个状态。可靠对应和版本证据成立后才能抑制重复获取；同名或数量接近不能代替判断。来源有冲突时保留审核，不把任务伪装成成功。

Costuan 是当前专用来源链路，浏览器扩展独立安装；部分资料留存不放宽严格暂存规则，实际插件版本需在其独立项目核对。其他网站可人工记录出处，不代表已有自动适配器。见[来源资料](source-evidence-local-admission.md)及[Costuan 入库](local-ingest-closed-loop.md)。

## 首页与浏览偏好

首页顶部的三个圆形入口固定为“最新”“重新发现”“随机”，点击后直接切换动态流。“最新”优先展示较新的内容，“重新发现”让较早的精选内容再次出现；再次点击“随机”会换一批。这三个入口不再打开原来的精选故事弹窗，其他故事浏览能力仍保留。

桌面侧栏和手机“更多”菜单显示图库统计：规范博主、独立作品和照片。统计面向完整图库，不随当前分类或搜索条件变化；作品和照片按符合展示规则的默认本地副本计算，多来源、额外副本和多个分类标签不会重复增加计数。视频不计入照片数，回收媒体和附件也不计入照片数。

没有指定主副本时，仅一份符合展示条件的副本参与作品和照片统计；无 Post、停用、未匹配或归属不一致的副本不参与“唯一可用副本”的判断。有多份可用副本且尚未选主时，统计不会任意选一份；已明确选择但不可用的主副本也不会自动替换为次副本。

博主卡片的“套数”和作品列表分页数目前采用**可浏览图集条目（Post）**口径，保留未选主的历史展示条目。它们不总等于侧栏的独立 Work 数：例如同一 Work 有两份可浏览副本但尚未选主，卡片 / 列表显示 2 条，侧栏暂不计入该 Work 及其照片。明确选择可用主副本后，这个 Work 在两处都计为 1。统计不会改写主副本选择；不能把展示条目数直接当作独立作品总量。

桌面侧栏默认点击展开 / 收起：收起时点击顶部品牌位置展开，展开后使用右上角按钮收起。管理员可在“设置 → 常规设置 → 浏览偏好”切换为悬停方式。交互方式和点击模式的展开状态保存在当前浏览器，不是全站设置；目前没有访客专用的设置页。网站强调色则是管理员保存后共享的站点设置，支持蓝、紫、玫红、青绿、琥珀和灰。

## 图库与自有目录

- 图库导航提供“全部图库”和 Cosplay、写真、自拍、福利姬四个分类。分类属于规范博主，一位博主可以有多个标签；未分类博主仍在全部图库显示。管理员可在全部图库的博主卡片上“编辑分类”，分类公开用于浏览。
- R15 / R18 分级筛选和徽标只在全部图库显示，四个分类页不叠加分级筛选。博主“喜欢 / 保留”偏好及其筛选仅对管理员开放，与作品的点赞、收藏是不同功能。
- `/library` 每页 60 位博主；分类、适用的分级 / 管理员偏好和名称 / 别名对完整可访问身份集合联合筛选后分页。旧链接或结果变化导致页码越界时，自动回到最后有效页并替换地址，保留筛选；没有结果时回到第一页。重复点击当前选项不重复请求。主动筛选不恢复旧滚动位置，从图集返回保留原筛选与阅读位置。
- 规范博主可以关联多个本地目录；图集列表每页 24 套摘要，选中后才加载完整媒体。
- 图集内 Viewer 切换 / 关闭复用当前详情与背景网格；跨路由回访仍可能重新请求。
- Work 是稳定身份；主副本与额外副本不按文件名自动合并。
- 资源目录按每位博主的生效时间从早到晚编号，再独立应用显示升降序、筛选与分页。
- 来源顺序估算是固定确认的排序依据，不是真实发布日期；文件名和来源 NO 不随自有 NO 改写。
- 目录派生数据持久保存，后台增量更新；初始化、更新中或失败状态明确，不将部分全库当成完整导出。

见[资源目录](own-resource-catalog.md)、[架构](how-it-works.md)。

## 继承的媒体浏览能力

保留首页、短片、图库、搜索、赞过、收藏集、分享与回收站等 Foldergram 浏览能力。图片和视频格式、缩略图 / 预览行为见[媒体处理参考](media-processing.md)；角色和分享范围见[安全](security.md)。

短片包含独立视频和图集内的每个可见视频，可按随机、最新或推荐浏览。每个视频独立播放、下载，并可回到所属图集的对应位置；点赞和收藏仍作用于所属作品。分页保持当前队列顺序，实时跳过已回收或不再可见的视频；推荐沿用已有规则，不增加同图集连续出现的抑制。

图库视频查看器与短片先尝试播放原件，遇到兼容性问题时才按需尝试无损转封装或兼容预览；打开视频不会为了检查预览而提前触发转换。图片继续使用缩略图 / 预览缓存。首次生成缓存或兼容文件可能需要等待，不能据此保证所有原件都能直接播放。分享页使用自己的授权媒体路径。

Foldergram 的保留 `carousels/` 目录规则是另一种 Post 组织方式，其 2–20 项限制不是 CosGallery 每套图集的媒体上限。不要为入库而把完整图集强制改成这种目录结构。

## 尚未实现或受限

- 复杂合集自动拆分、任意已有 Work 合并。
- 全部历史关系纠正与专项清理的通用网页工具。
- 任意资源站自动采集、任意压缩包无条件解压入库。
- 远程访问客户端本地盘符、全平台一致的 Windows 回收站行为。
- 公网多用户隔离、全局初始化性能保证、无条件解码所有原件。

[删除博主](unused-manual-creator-deletion.md)适用于所有来源的身份：先停用，再核对本地作品、目录和任务等阻断关联，确认随删来源资料的完整范围。执行前再次检查，不删除本地文件。
